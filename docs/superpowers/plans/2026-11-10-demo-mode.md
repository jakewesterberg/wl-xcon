# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **The PI's process rule of 2026-11-07 governs:** "a plan is a design and a list of tests, built once"; one review of the whole build, plus his welfare review of the two welfare-listed changes (Task 5). No per-task review loop, no re-proofs.

**Goal:** A person plays the pop-out search with the mouse as the eye, scored by the rig's own eye rules, in a private copy of the rig service started by `wlx demo`, or from a live rig's own page as a demo session for the test monkey; XC-013 closes.

**Architecture:** A new sample source, `pointer.Source`, reads the page's pointer reports from a fourth link socket and feeds `pointer.Pointing`, a `gaze.Tracked` subclass built as `simeye.Seeing` is, which also answers the non-gaze guards from keys, paces each frame to the wall clock and publishes the screen it shows as a `Drawn` message. `wlx taskd --demo` is the rig service with its own folder, `REFERENCE` alone and the simulators; `Service._open` gains the two approved changes so a live rig's page can open a demo too. `wlx serve` takes `POST /gaze` under `/commands`' gates and draws each `Drawn` with the exact drawer, labeled, on a thread of its own; the page shows it and steers. `wlx demo` runs the two children and opens the session and the run.

**Tech Stack:** Python 3.11-3.13, the existing `wl_xcon` package, pytest (+ xdist, Playwright Chromium and WebKit), pyzmq and msgpack (the console extra), numpy (already a dependency), the standard library's `struct`, `zlib`, `fcntl`, `tempfile` and `webbrowser`. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-06-demo-mode-design.md`, approved by the PI on 2026-11-07 ("Approve both and the design", its §15). Section numbers below are its.

## Review Focus

1. **A demo for a real animal on a live rig** is refused before anything is written, including where a far departure would otherwise pose its question; and a demo session runs on the simulated card and pump though the service was built with others (Task 5).
2. **Keys between frames**: a press and release between two frames is seen once; counts rebase at a trial's first frame, so a press in the gap never fires the next trial's `Pressed` (Task 2).
3. **A page's stall**: inside `LIVE_S` the last position is held and counts toward a hold; past it, tracker loss under `tracker_lost`, never `blink`; off the drawing is gaze away, never tracker loss (Task 2).
4. **The mouse and the simulated eye agree**: the eye's own samples sent as reports score the same outcomes through `Pointing` as through `Seeing` (Task 2).
5. **Steering**: kept off the drawing, released by Escape, the page closing or `STEER_HOLD_S`; another page meanwhile 409 (Task 8).
6. **Screens faster than drawings**: the newest drawn next, the drawing never in the rig service's process (Task 7).
7. **A crashed demo**: never resumed, only ended; a rig service started after a private demo finds nothing of it (Tasks 4, 10).
8. **The pop-out's 0.3 s landing bound under a hand** (§3.3): the PI's try-out decides; if a hand cannot land in time the bound becomes a setting in wl-xtasks, reviewed with the task, never changed here.

### Task 2: The pointer source and `Pointing`, in process (§3.3-§3.5)

**Files:** Create `wl_xcon/pointer.py`; Test `tests/test_pointer.py`.
**Interfaces:**
- `pointer.MESSAGE = struct.Struct("<IddBH9H")`, 41 bytes: a sequence number (`wlx serve`'s forwarding count, Task 8), x and y in degrees (+y up), flags `OVER = 1` (over the drawing), `B_HELD = 2`, `BUTTON = 4`, the keys held (bit `k-1` for key `k`), and each key's running press count modulo 65536. `pointer.pack(seq, x_deg, y_deg, *, over, b, button, held, presses) -> bytes`.
- `pointer.MAPPING = dataclasses.replace(simeye.MAPPING, why="the mouse, in degrees")`; the map never changes, no recentering (§14 item 5).
- `pointer.Source(receive: Callable[[bytearray], int], *, seed: int, noise_deg: float = simeye.NOISE_DEG)`. `receive` reads one waiting message into the buffer and returns its size, or -1 with none waiting. `poll(at) -> eye.Sample | None`: drains at most `DRAIN` messages; keeps the one of highest sequence (an older one counted in `stale`); counts and drops one of the wrong size or not finite (`malformed`); holds the newest current for `LIVE_S` on `at`; returns `None` past that or while B is held (tracker loss); off the drawing, `AWAY_DEG`; otherwise the position **eased** from the last on the minimum-jerk profile `simeye` flies (`10τ³ - 15τ⁴ + 6τ⁵`) over the frames since the previous report arrived, at most `LIVE_S` (planner's call), plus Gaussian noise of `noise_deg` per axis from `random.Random(f"{seed}: the mouse's noise")`, one `EyeReading` for both eyes. `new_trial()`: all but the newest waiting discarded, press counts rebased. `held(key)`, `went_down(key)`, `went_up(key)` (edges against the previous frame, from the counts and the held mask), `button`.
- `pointer.Input(key: int, guard: Guard)`; `pointer.inputs(trial) -> tuple[Input, ...]`: each `Pressed`/`Released`/`Response` device (one key a device), `FeatureAbove` source and `ChairStill`, numbered 1-9 in the order the states first name them; `pointer.TooManyInputs(ValueError)` naming them past `KEYS`.
- `pointer.Pace(frame_period, *, clock=time.perf_counter, sleep=time.sleep)`: `start()` at a trial's first frame; `wait(frame)` sleeps until that frame's moment; a frame already late runs at once and moves the schedule on, never a catch-up burst.
- `pointer.Pointing(gaze.Tracked)`: `__init__(source, trial, frame_period, values, *, pace, keys, index=0, drawing=None, publish=None)`, a fresh `Tracker()` and `Detector()` (`Tracked.__init__(self, Tracker(), MAPPING, trial, frame_period, values, source=source)`). `display`: pace first (`start` on frame 1, then `wait`), then `Tracked.display`, then the frame's key edges. `happened`: `Pressed`/`Response` on the key's down edge, `Released` on its up edge, `FeatureAbove` while held, `ChairStill` while not held, `Touched(window)` while the button is down and `in_window(window)`, `Onscreen` on the first frame after the visible stimuli changed; anything else `Tracked.happened`.
- `pointer.worlds(source, *, pace, drawing=None, publish=None) -> Callable[[Trial, dict, int], Pointing]`: `source.new_trial()` on each call.
